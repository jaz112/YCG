# Team photographs

Place approved images here as `founder-photo.jpg` and `partner-photo.jpg`.
Then update `src/data/team.ts`: set the corresponding photo to
`/images/team/founder-photo.jpg` or `/images/team/partner-photo.jpg`, add the real
name, role, approved biography and descriptive photoAlt. Do not set a photo path
before the file exists. Null values render an explicit placeholder.

Use natural colour and a consistent 4:5 crop, ideally 600 × 750 or 1200 × 1500.
Keep original uploads privately; publish only approved web copies with metadata
removed. Never add private originals or personal documents to the repository.
